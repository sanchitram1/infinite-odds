# Infinite Odds Backend

Backend server for the Infinite Odds game, handling game state validation, contract signatures, and database operations.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Configure environment variables:

```bash
cp .env.example .env
```

Then edit `.env` with your configuration values.

3. Start the server:

Development mode with hot reload:

```bash
npm run dev
```

Production mode:

```bash
npm start
```
